#

# values now that setFPMode() no longer sets the x87 _PC_24 precision clamp on 32-bit x86 (that clamp
# previously pulled win32 to 85594C58/7EB5D952, a separate lockstep group). --allow-double-divergence
# is therefore NO LONGER needed for win32; all three architectures match outright.
#
# Captured: macOS arm64, build macos-generalsmd-sdl3-bgfx (Release), 14/06/2026.
